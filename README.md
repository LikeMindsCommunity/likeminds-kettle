# Getting Started

## Requirements
```
Go
Redis 
```
## Steps
1. Clone the repository:
2. Set up the redis URL with the correct port in the cache/redis.go file.
3. Create an .env file in the root directory of the project and add necessary details and credentials.
4. Build the project using the following command:
```
go build . 
```
5. Run the project using the following command:
```
./Likeminds-authentication
```

And that's it! Your Go project is now set up and ready to use.
